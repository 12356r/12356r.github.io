# 郑州大学校园探索 · Zhengzhou University Campus Explorer

> 遇见郑大，遇见更好的自己。
>
> 一个以「校园旅游导览 + 校园生活介绍」为核心的郑州大学校园介绍网站。
> **本站是校园文化与信息导览项目，非郑州大学官方网站。**

---

## 一、这个项目是什么

项目把郑州大学的公开信息整理成一个可以浏览、筛选、检索、收藏的多页面网站，包含十个页面：
首页、校园风光、校园地图、宿舍生活、校园美食、社团活动、校园贴吧、资讯与公告、关于本站。

设计语言为「清新校园风 + 蓝白配色 + 高质量卡片 + 大面积留白」，
不采用赛博朋克、深色霓虹或炫技式三维效果，视觉效果以版式、留白、真实信息层级为主。

### 一个必须说明的设计前提

> 本站**没有**获得郑州大学授权，也**没有**可用于商用的校园实景照片。

因此项目做了两个明确的取舍：

1. **配图全部是本地生成的 SVG 示意插画**，页面与卡片上明确标注「示意图 · 非实景照片」，
   绝不使用其他高校照片冒充郑大实景。
2. **信息分三级核验**，页面上以徽章区分，不把「待核验」的内容写成事实：

| 徽章 | 含义 | 展示规则 |
| --- | --- | --- |
| **已核验** | 名称与关键信息可在学校官网/公开权威来源中查到 | 页面给出可点击来源链接 |
| **待核验** | 来自公开资料，但未获得官方页面确认 | 明确提示，不提供未经核实的细节 |
| **示例** | 用于演示版式与交互的示例数据 | 明确标注，不提供真实报名/价格信息 |

## 二、技术栈

| 类别 | 选择 |
| --- | --- |
| 构建 | Vite 5 |
| 框架 | React 18 + TypeScript（严格模式） |
| 路由 | React Router 6（`BrowserRouter`，支持前进/后退与直接打开子页面） |
| 地图 | Leaflet 1.9 + OpenStreetMap 标准瓦片（无需 API Key） |
| 图标 | lucide-react |
| 样式 | 原生 CSS（设计令牌 + 组件类 + 页面类，四层结构） |
| 主题 | 浅色 / 深色，跟随系统偏好或手动切换，写入 `localStorage` |
| 状态 | React Hooks；收藏与坐标标注使用 `localStorage` |

无 UI 框架、无 CSS-in-JS、无重型动画库，首屏与交互均为原生实现。
页面按路由分包（`React.lazy` + `Suspense`），地图与 Leaflet 只在进入地图页时加载。

## 三、安装与启动

需要 Node.js 18 及以上（开发使用 Node 24 验证通过）。

```bash
# 1. 安装依赖
npm install
# 或
pnpm install

# 2. 启动开发服务器（默认 http://localhost:5173，本项目配置为 5180）
npm run dev

# 3. 构建生产包
npm run build

# 4. 预览生产包
npm run preview

# 5. 仅做类型检查
npm run typecheck
```

> **关于 pnpm**：仓库内的 `.npmrc` 设置了 `node-linker=hoisted`，
> 避免 pnpm 的符号链接在部分 Windows 环境下导致 Vite 找不到 `rollup` / `esbuild`。
> `esbuild` 同时被显式列为 devDependency，请勿删除。

### 环境变量

**不需要任何环境变量**。地图使用 OpenStreetMap 公共瓦片，无需申请 Key。
若后续替换为需要鉴权的地图服务（如高德、Mapbox），
请在 `src/pages/MapPage.tsx` 的 `L.tileLayer(...)` 处替换地址，并通过 `.env` 注入 Key。

## 六、数据与核验机制

### 数据文件

所有内容都在 `src/data/` 下，与页面代码完全分离。修改内容不需要动组件。

每条数据尽量包含：唯一 `id`、名称、简介/描述、分类、所属校区、图片、
`coords`（经纬度，仅在核验后填写）、`sources`（来源链接数组）、
`verification`（`verified` / `pending` / `illustrative`）、`updatedAt`。

### 待核验内容（`pending`）

- **杏坛、情人湖**：位置与介绍已由项目方补充，但尚无实景照片，也未在学校官方页面核对，因此保留「信息待核验」并附来源说明。
- **厚山的「全国高校十大最美校园地标」**：说法常见于校园资料，原始出处未核对，正文中已注明「仅作参考」。

### 示例内容（`illustrative`）

- 社团活动：6 条示例卡片。**没有**真实活动、主办方、报名链接。
- 宿舍场景：3 张示意插画。**没有**房型、床位数、空调/卫浴配置、收费标准。
- 杏坛、情人湖及三个分校区：使用示意插画，名称与位置信息待核验。

### 如何把示例数据换成真实内容

1. 打开 `src/data/content.ts`，找到对应条目；
2. 补全真实字段（名称、简介、位置、价格等），填写 `sources` 官方来源链接与 `updatedAt`；
3. 把 `verification` 从 `'illustrative'` 改为 `'verified'`；
4. 页面徽章会自动变为「来源已核验」。

> 请不要在未核实的情况下把 `verification` 改成 `verified`，
> 徽章是对读者的承诺。

## 七、图片资源配置说明

### 配色与风格

整套配色走**暖色系**：奶油底色（`#fffaf4`）+ 陶土橙主色（`#c2562a`）+ 暖褐文字（`#4a2f22`），
阴影也改成暖褐而非冷灰，圆角整体调大（`--r-md` 14→16、`--r-xl` 28→30）。

- 配色集中在 `src/styles/tokens.css`，改主色只需动 `--c-primary` 系列；深色模式是暖棕夜色（`#241a14`）。
- 页面里零散的遮罩/阴影色（原先是 `rgba(9,30,51,…)` 的冷蓝）已统一换成暖褐 `rgba(58,32,20,…)`。
- 插画（`SceneArt.tsx`）的六套季节配色同步调成暖调：天空蜜桃色、地面橄榄色、建筑米色；水面保留青蓝，避免失去"水"的质感。

## 横幅插画

没有实景照片的板块页（宿舍、美食、社团、地图、名师、贴吧、思政育人等）统一用 `src/components/YouthBanner.tsx`
绘制的「青春正能量 · 红色」横幅：朝霞渐变天空、初升太阳与光芒、金色五角星、红绸带、校园天际线。

- 校园风光、地点详情、食堂详情这类有实景照片的页面仍用照片（含贴吧页的「郑州大学」题字墙，`public/images/board/`），`PageBanner` 有 `image` 时优先用图。
- 底色与压暗层为 `--c-` 令牌之外的专用样式，见 `src/styles/education.css` 里的 `.page-banner--youth`。

## 校园贴吧（需要后端）

「所有人可见」意味着必须有服务端。项目里用一个零依赖的 Node 服务同时托管 `dist` 与留言接口：

```bash
pnpm build              # 先把前端构建到 dist
node server/index.js    # 启动后访问 http://127.0.0.1:5190/
```

- 接口：`GET /api/board/posts`、`GET /api/board/posts/:id`（单条，供收藏页取回）、`POST /api/board/posts`（JSON；图片走 dataURL；可带 `category`）、`DELETE /api/board/posts/:id`（带 `x-delete-token`）。
- 收藏：每条留言右上角书签图标可加入「我的收藏」（存 `board-<id>` 到 localStorage），收藏页按 id 拉取内容，作者删帖后显示为失效条目；`/board?post=<id>` 可直接定位并高亮该留言。
- 食堂档口同样可以收藏（存 `pick-<id>`），收藏页直接读本地数据渲染，不需要后端。
- 回复：`POST /api/board/posts/:id/replies`（JSON，纯文字）、`DELETE /api/board/posts/:id/replies/:replyId`（带 `x-delete-token`）。回复只做一层，正文 300 字上限、每帖最多 100 条、同一 IP 4 秒冷却。
- 四个板块：`种草贴` / `交友贴` / `心事贴` / `经验贴`。发布时四选一，列表可按板块筛选，帖子头部显示彩色板块标签。
- 存储：帖子写到 `server/data/posts.json`，照片存 `server/data/uploads/`（两者都在 `.gitignore` 里，默认空板启动）。
- 限制：正文 800 字、单帖最多 3 张图、单图 4MB、同一 IP 8 秒冷却、最多保留 300 条。
- 匿名：不收集姓名与账号；昵称由帖子 id 派生（如「勤奋的郑大同学」）；删除令牌只存在发布者自己的浏览器里。
- 开发时 `pnpm dev` 会把 `/api`、`/uploads` 代理到 5190（见 `vite.config.ts`）；直接用 `pnpm preview` 打开贴吧会提示「连不上留言服务」。
- 正式对外开放前，建议补上敏感词过滤与人工清理入口——现在只有「删除自己」这一项管理能力。

### 如何换成真实照片

1. 把授权图片放进 `public/images/`，例如 `public/images/library.jpg`；
2. 在数据条目中填写 `image: '/images/library.jpg'`；
3. `Media` 组件会自动优先使用图片，加载失败时**自动回退**到插画，并保留「示意图」逻辑。

```ts
{
  id: 'library-main',
  name: '图书馆',
  image: '/images/library.jpg',   // ← 新增这一行即可
  art: { kind: 'library', seed: 5, mood: 'spring' }, // 仍作为加载失败的回退
  verification: 'verified',
  sources: [{ label: '郑州大学图书馆', url: 'https://library.zzu.edu.cn/' }],
}
```

- 只使用经授权的郑州大学实景图片，或学校官方公开发布的图片；

## 八、地图说明

- 底图：OpenStreetMap 标准瓦片 `https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png`，
  遵守其[使用政策](https://operations.osmfoundation.org/policies/tiles/)（适合低流量展示，正式上线建议自建瓦片或换用商业服务）。

- **坐标策略**：站点未获得经核验的校园建筑经纬度，因此**不在地图上标注任何未经确认的位置**。
  当某地点在数据中补上 `coords: { lat, lng }` 且经核验后，地图会自动生成标记。
- **坐标标注模式**：选择地点 → 点击「标注坐标」→ 在地图上点击，
  坐标保存在本机 `localStorage`（键名 `zzu-explorer:coords`），只作个人参考，不会被当作官方数据。
- **降级处理**：瓦片加载失败时，地图区域会显示提示与两个备用入口（OpenStreetMap、学校官方校园地图），
  页面其他内容不受影响。
